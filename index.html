Why agents fail on real work

A model that's 90 % reliable per step is 59 % reliable over five steps. Real tasks are ten to fifty steps. If the agent executes everything itself — fetching, parsing, transforming, deploying — compounding error does the rest, and you end up watching it.

0.9⁵ = 59%agent does every step
0.9³ = 73%agent makes 3 decisions, scripts do the rest
→ 100%scripts + tests, once they work

D.O.E. moves everything with a right answer into tested code and leaves the agent exactly one job: deciding what to run next. Then it makes the system self-annealing — every failure becomes a test, a rule, and a lint, so month three is dramatically better than week one.
