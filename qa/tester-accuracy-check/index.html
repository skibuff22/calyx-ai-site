How it works

For each point: error = tester reading − reference load, and % error = error / reference load × 100. A positive error means the tester reads high. A point is PASS when the absolute % error is no more than the tolerance you enter; the overall result is PASS only when every point with both readings passes. A row without both readings gets no result. Check: reference 10.00 kN, tester 10.15 kN gives +0.15 kN and +1.50 %, which is FAIL at ±1 % and PASS at ±2 %.

This is an in-house check between calibrations, not a calibration. The tool does not choose the check loads, the number of points or the tolerance, and it takes the reference reading as correct.
